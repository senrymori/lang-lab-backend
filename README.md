# Language Lab — сервер

Аккаунты и доступ, репетитор и тренировки для всех учеников. Ядро обучения — пакет `lp` из
`../lang-lab-platform` (подключён как редактируемая зависимость, код не копируется).

## Запуск для разработки
```
uv sync
uv run alembic upgrade head
uv run uvicorn app.main:app --reload
```
Ничего ставить в систему не нужно: без `LANGLAB_DATABASE_URL` поднимается свой Postgres из `var/pg`
(пакет `pgserver`) и останавливается вместе с сервером. Вручную: `uv run python -m app.devdb status|stop`.
Всё лишнее удаляется вместе с папкой `var/`.

## Коды доступа (закрытая бета)
```
uv run python -m app.codes new --note "Аня, коллега" --days 90 --expires 14
uv run python -m app.codes list
```
`invite` — личный код: срабатывает на одну регистрацию и сгорает. `promo` — на много регистраций,
для маркетинга (`--kind promo --uses 100`). Регистрация закрывается на `LANGLAB_MAX_LEARNERS` (10).

## Заявки на доступ
Форма на langlab.uk (имя и почта) → worker сайта проверяет Turnstile → `POST /intake/access-request {name, email}`
с заголовком `X-Intake-Key` (`LANGLAB_INTAKE_KEY` или `~/.config/lp/intake.key`, тот же ключ — секрет `INTAKE_KEY`
у worker; без ключа приём выключен). Писем никто не получает: заявки лежат в таблице `access_requests` и видны в
админке на «Заявках». Приглашение из заявки или отказ её удаляют; повторная заявка с того же адреса обновляет имя,
с адреса ученика — не сохраняется.

## Вход (без пароля)
1. `POST /auth/start {email}` — вход; `{email, code, name}` — регистрация по коду. Ответ — `{request}`,
   секрет приложения. В письме — ссылка и шестизначный код; ответ одинаковый, известен адрес или нет.
2. Дальше одно из двух:
   - ссылка открывает страницу с кнопкой «Войти» (сам GET ничего не делает — почтовые сканеры не
     войдут за ученика), а приложение опрашивает `POST /auth/poll {request}`: 202 — ждём, 200 — сессия,
     410 — устарело. Письмо можно открыть на телефоне — войдёт приложение на Маке;
   - код вводится в приложении: `POST /auth/code {request, code}` → сессия (5 попыток).
3. Дальше `Authorization: Bearer <token>`: `GET /me`, `POST /auth/logout`. Страница ходит с кукой. Токен
   никогда не идёт в URL (URL оседают в логах): WebSocket, который не может послать ни заголовок, ни куку,
   берёт `POST /auth/ws-ticket` → `?ticket=` — одноразовый, на 60 с.

Код доступа тратится только при подтверждении почты: опечатка в адресе инвайт не сжигает. Лимиты:
3 письма на адрес за 15 минут, 20 запросов с одного IP в час (за Cloudflare —
`LANGLAB_BEHIND_CLOUDFLARE=1`). Письма уходят через Resend (ключ `LANGLAB_RESEND_KEY` или
`~/.config/lp/resend.key`), без ключа — печатаются в консоль; `LANGLAB_MAIL_BACKEND=console` — не слать
даже с ключом. Ссылки ведут на `LANGLAB_PUBLIC_URL`.

## Репетитор и тренировки
Всё, кроме входа, `/me` и `/health`, — приложение `lp` (его API и WebSocket репетитора),
смонтированное в корень под входом этого сервера (`app/hosting.py`). Страницу `lp` (`/`, `/static/`,
`/manifest.webmanifest`) сервер не отдаёт — 404: интерфейс живёт только в приложении на Маке. `lp` работает в режиме
`LP_HOSTED`: ученик — аккаунт отсюда, его файлы — в `var/data/<id>`, записи — в `var/recordings/<id>`.
- **Модели по режимам:** урок и плейсмент — `gpt-6.1-sol` (`LANGLAB_MODEL_LEARN|PLACEMENT`); строку
  ожидания, пока репетитор думает, `lp` пишет сам на `gpt-6-luna` — её расход тоже пишется на ученика.
  Ключ сервера — `LANGLAB_OPENAI_KEY` или `~/.config/lp/openai_server.key`: проект OpenAI, где разрешены
  только эти модели и `omni-moderation-latest` (модерация; без него она не работает — в логе
  «moderation failed»), с жёстким лимитом в месяц.
- **Распознавание речи** — Gemini (две модели сразу, см. `lp/stt.py`): ключ `LANGLAB_GEMINI_KEY` или
  `~/.config/lp/gemini.key`, платный тариф.
- **Расход** каждого вызова пишется в таблицу `spend` (видно в админке); денежных лимитов нет — ученика
  ограничивает только число уроков.
- **Спам токенами** (`app/abuse.py`): если одна живая сессия тратит слишком быстро (`LANGLAB_SPIKE_WINDOWS`,
  по умолчанию $2 за 20 мин или $4 за час — только внутри этой сессии, подряд идущие уроки не суммируются),
  `gpt-6.1-sol` читает, что ученик писал и говорил. Спам — ученик блокируется (`blocked_reason` «авто: …»),
  урок останавливается; похоже на урок — идёт дальше, следующая проверка через ещё $2. Все проверки —
  в таблице `spend_alerts` и в админке на «Обзоре»; разблокировка — кнопкой в «Учениках».
- **Скрипт на распознавании речи** (ответы, голосовые, тренировки): каждая попытка считается в момент запроса. Больше 5 за
  5 секунд — красный флаг в «Подозрительном расходе» (не чаще раза в минуту), 20 и больше за 10 секунд — ученик блокируется
  (`app/hosting.py: burst`), выходит со всех устройств, урок останавливается. Человек так быстро не говорит.
- **Модерация** (`app/hosting.py: moderate`): всё, что ученик пишет и говорит (чат, голосовые, ответы в заданиях), в фоне
  проверяет бесплатная модерация OpenAI (`omni-moderation-latest`). Помеченное — красный флаг в «Подозрительном» со
  словами ученика; одно самоповреждение — отдельная пометка «возможно, человеку плохо», не блокирует никогда. Второй флаг
  (за всё время) — лемур в уроке предупреждает о бане, третий (`LANGLAB_MODERATION_BLOCK_AFTER`) — ученик блокируется,
  как при спаме. Рамку разговора (не чужая работа, без вреда, без
  мнений о политике) держит сам репетитор — `prompts/tutor.md`, «Рамка».
- **Перед занятием** проверяется срок доступа (`access_until`) и остаток уроков; урок и определение уровня
  списывают по одному. Одно занятие за раз: второе (на другом языке) не начнётся, пока идёт первое.
- **Речь** (распознавание — Gemini, голос игр — Azure/Kokoro) работает только внутри урока или открытой
  тренировки: страница шлёт их пропуск в `X-LP-Pass` (урок — в `replay` по WebSocket, тренировка — со
  страницей игры, на 3 часа). Распознавание пишется в расход ученика и считается детектором спама.
- **Лимиты:** запись голоса ≤ 2 мин и ≤ 10 МБ, сообщение ≤ 2000 символов, ≤ 20 сообщений репетитору в минуту
  на урок (сколько бы вкладок ни было), не больше 3 своих сообщений подряд (текстом или голосом, не ответов на
  задания), пока репетитор не ответил (`LANGLAB_UNANSWERED_MAX`): дальше ввод и микрофон ждут его ответа, ≤ 12 распознаваний и ≤ 60 озвученных строк в минуту на ученика
  (`LANGLAB_HEAR_PER_MINUTE`, `LANGLAB_SAY_PER_MINUTE`), поле профиля ≤ 1000 символов (дописанное
  репетитором сверх — gpt-6-luna пересказывает до 700).
- **Чистка** (`app/cleanup.py`, каждые 6 часов): записи голоса и озвученные строки старше недели.
- **Закрыто для учеников:** мастерская игр, git-синхронизация и всё, что вызывает `claude -p`. Игры
  собираются только из одобренных шаблонов.
