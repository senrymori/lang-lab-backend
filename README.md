# Language Lab — сервер

Аккаунты и доступ, репетитор и тренировки для всех учеников. Ядро обучения — пакет `lp` из
`../learning-lang-platform` (подключён как редактируемая зависимость, код не копируется).

## Запуск для разработки
```
uv sync
uv run alembic upgrade head
uv run uvicorn app.main:app --reload
```
Ничего ставить в систему не нужно: без `LANGLAB_DATABASE_URL` поднимается свой Postgres из `var/pg`
(пакет `pgserver`) и останавливается вместе с сервером. Вручную: `uv run python -m app.devdb status|stop`.
Всё лишнее удаляется вместе с папкой `var/`.

## Коды доступа (закрытая бета)
```
uv run python -m app.codes new --note "Аня, коллега" --days 90 --expires 14
uv run python -m app.codes list
```
`invite` — личный код: срабатывает на одну регистрацию и сгорает. `promo` — на много регистраций,
для маркетинга (`--kind promo --uses 100`). Регистрация закрывается на `LANGLAB_MAX_LEARNERS` (10).

## Вход (без пароля)
1. `POST /auth/start {email}` — вход; `{email, code, name}` — регистрация по коду. Ответ — `{request}`,
   секрет приложения. В письме — ссылка и шестизначный код; ответ одинаковый, известен адрес или нет.
2. Дальше одно из двух:
   - ссылка открывает страницу с кнопкой «Войти» (сам GET ничего не делает — почтовые сканеры не
     войдут за ученика), а приложение опрашивает `POST /auth/poll {request}`: 202 — ждём, 200 — сессия,
     410 — устарело. Письмо можно открыть на телефоне — войдёт приложение на Маке;
   - код вводится в приложении: `POST /auth/code {request, code}` → сессия (5 попыток).
3. Дальше `Authorization: Bearer <token>`: `GET /me`, `POST /auth/logout`.

Код доступа тратится только при подтверждении почты: опечатка в адресе инвайт не сжигает. Лимиты:
3 письма на адрес за 15 минут, 20 запросов с одного IP в час (за Cloudflare —
`LANGLAB_BEHIND_CLOUDFLARE=1`). Письма уходят через Resend (ключ `LANGLAB_RESEND_KEY` или
`~/.config/lp/resend.key`), без ключа — печатаются в консоль; `LANGLAB_MAIL_BACKEND=console` — не слать
даже с ключом. Ссылки ведут на `LANGLAB_PUBLIC_URL`.

## Тесты
`uv run pytest` — у прогона свой временный Postgres и папки данных, письма никуда не уходят.
